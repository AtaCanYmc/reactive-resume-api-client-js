# Security Policy

## Supported Versions

We actively maintain and provide security patches for the following versions of `reactive-resume-api-client-js`:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this SDK, please do **NOT** open a public issue. Publicly disclosing a vulnerability can put users and Reactive Resume instances at risk.

Please report security issues using one of the following confidential channels:

1. **GitHub Private Vulnerability Advisory (Preferred):**
   Submit a private advisory report directly via [GitHub Security Advisories](https://github.com/AtaCanYmc/reactive-resume-api-client-js/security/advisories/new).

2. **Direct Email:**
   Send an email to [atacanymc@gmail.com](mailto:atacanymc@gmail.com) with the subject line `[SECURITY] reactive-resume-api-client-js`.

### What to Include in Your Report

To help us investigate and resolve the issue quickly, please provide:
- A clear description of the vulnerability.
- Steps to reproduce or a minimal proof-of-concept (PoC).
- Potential impact and affected versions.
- Any proposed remediation or patches, if available.

### Response & Disclosure Process

- **Acknowledgment:** We aim to acknowledge receipt of your vulnerability report within 48 hours.
- **Assessment:** We will verify the issue and keep you updated on progress.
- **Resolution:** A patch will be developed, tested, and published as a new release on npm.
- **Credit:** If you wish, we will credit your contribution in the security advisory and release changelog.
